# Perfil pessoal — Arthur

Site de perfil pessoal feito com HTML, CSS e JavaScript, incluindo a foto enviada.

## Arquivos
- `index.html` — estrutura do site
- `css/style.css` — aparência e adaptação para celular
- `js/script.js` — menu mobile e ano automático
- `img/foto-perfil.png` — foto do perfil

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra a pasta `perfil_arthur` no Visual Studio Code.
3. Abra o arquivo `index.html` usando a extensão **Live Server**. Também é possível abrir o HTML diretamente no navegador.

## Personalização
Edite o texto em `index.html` para acrescentar seus dados, interesses e contatos. Para mudar a foto, substitua `img/foto-perfil.png` por outra imagem mantendo o mesmo nome.
